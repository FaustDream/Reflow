## 0.2.0（2026-10-29）

平台收敛到 4 个购物平台，外卖单从购物单里拆出来独立成组，并新增跨平台数据总览。

### 平台支持（收敛后）

| 平台 | 捕获方式 | 登录方式 |
|---|---|---|

| 京东 | 被动捕获（按年遍历 + 年内翻页） | 二维码（登录页提取） |
| 淘宝 | 主动抓取（`lib.mtop` 全量）+ 被动捕获 | 二维码（原生接口） |
| 拼多多 | 被动捕获 + 自动翻页 | 二维码（登录页提取） |

- 2026-10-27 下架 1688 / 快手小店 / 得物 / 饿了么；2026-10-29 下架 美团外卖。
  适配器代码保留，在 `shared/platform-visibility` 里加回 id 即可恢复
- 下架平台的历史订单仍留在本地缓存，只是不再计入顶部合计与总览统计

### 新增：数据总览

- 侧栏最上方「数据总览」：5 个 KPI + 年度分布 / 平台占比 / 月度分布 / 退款仪表 /
  每日热力 / 周内分布 / 平台明细 / 状态分布
- 三个切换：**全部 / 网购 / 外卖** 口径、**按单量 / 按金额** 维度、年份下拉
- 点年度柱形即可切换统计年份
- 图表全部手写 SVG/CSS（柱状堆叠、环形、仪表、日历热力），不引入图表库

### 外卖与网购分开

- 京东/淘宝订单里的外卖单自动识别，侧栏按「网购 / 外卖」分组，总览里也单独成平台
- 淘宝按官方 `extra.bizType` 判定（`5000` = 本地生活 / 外卖，`200` = 普通实物）
- 京东按「无商品页链接 + 餐品标题」判定（商城单一定有 `item.jd.com` 链接，外卖单没有）
- 外卖栏没有自己的适配器：登录、打开页面、抓取、导出全部回落到母平台，不需要单独登录

### 退款与支付成功分开统计

- 每笔订单归入 **支付成功 / 退款 / 关闭（取消、未付款）** 三类
- KPI 分列展示，柱状图改为蓝（支付）+ 红（退款）堆叠，热力图只按支付成功着色
- 新增「退款率」仪表；平台明细表增加「退款」列与「金额占比」

### 抓取修复

- **京东**：默认只显示近 3 个月，改为逐年切换 + 年内翻到底（只切年不翻页时每年仅 20 单）；
  订单页 SPA 化后接口返回 HTML 壳，改走被动捕获
- **淘宝**：改用页面内 `lib.mtop` 的 `queryboughtlistV2` 全量抓取；
  修复外卖单 `actualFee` 是对象时金额显示为空的问题
- **美团外卖**：接入官方 `window.H5guard` 签名器实现主动翻页（平台已下架，代码保留）

### 界面

- 隐藏底部状态栏（注入桥 / 适配器数 / 版本 / 水印），署名保留在「工具 → 关于」与导出文件属性
- 账号昵称修复：淘宝 `tracknick` 的 `\uXXXX` 转义还原、拼多多补上 `pdd_user_name` 来源

### 安全设计（不变）

- 不装证书、不改系统代理、不要管理员权限
- 不构造带签名的平台请求（sign 由页面官方 SDK 计算）
- 订单号精度保护、规则热更新校验、无授权限制

## 0.1.0（2026-10-21）

> ⚠️ **此段为历史记录，平台清单已过时。** 1688 / 快手小店 / 得物 / 饿了么（2026-10-27）、
> 美团外卖（2026-10-29）均已下架，当前只支持 4 个购物平台，见 0.2.0。

首个功能完整版本：10 个平台的订单捕获与导出全链路打通。

### 平台支持

| 平台 | 捕获方式 | 登录方式 |
|---|---|---|
| 闲鱼（买/卖） | 主动抓取 + 被动捕获 | 二维码（原生接口） |
| 淘宝 | 主动抓取（按月）+ 被动捕获 | 二维码（原生接口） |
| 1688 采购 | 主动抓取 + 官方 50 列导出 | 复用淘宝登录 |
| 京东 | 主动抓取（按年）+ 被动捕获 | 二维码（登录页提取） |
| 拼多多 | 被动捕获（观察法） | 二维码（登录页提取） |
| 快手小店 | 被动捕获 + 自动翻页 | 二维码（登录页提取） |
| 得物 | 被动捕获 + 自动翻页 | 小窗登录（无网页二维码） |
| 饿了么 | 被动捕获 + 自动翻页 | 小窗登录（无网页二维码） |
| 美团外卖 | 被动捕获 + 自动翻页 | 小窗登录（无网页二维码） |

### 核心功能

- **统一订单模型**：19 个核心列 + 各平台扩展列，跨平台合并导出
- **导出三形态**：Excel 单表（合并）/ Excel 多表（每平台一张）/ CSV（带 BOM）
- **导出双粒度**：导出本平台 / 导出全部；多账号时可选「仅当前账号」
- **多账号聚合**：同平台多账号独立会话，账号内去重
- **本地缓存**：订单按平台持久化，重启不丢，清空可删
- **自动翻页**：滚动加载型平台一键连续抓取
- **详情二次抓取**（闲鱼）：收货地址/运费/闲鱼币/支付宝交易号
- **商品图内嵌**：Excel 60×60 缩略图，webp 自动转码

### 界面

- 左侧平台列表 + 右侧单表，一屏完成所有操作
- 首次启动引导（原理说明 / SmartScreen 提示 / 选常用平台）
- 工具菜单：诊断快照（无敏感数据）、检查更新

### 安全设计

- 不装证书、不改系统代理、不要管理员权限
- 不构造带签名的平台请求（sign 由页面官方 SDK 计算）
- 订单号精度保护（16+ 位数字不被 JSON.parse 静默舍入）
- 规则热更新通道：SHA-256 校验 + schema 白名单，防投毒
- 无任何授权限制：导出行数恒等于捕获行数

### 已知限制

- 拼多多为被动捕获（接口契约待真机校准）
- 得物/饿了么/美团无纯二维码登录（平台网页端不提供）
- 未做代码签名：首次运行需通过 SmartScreen（见引导说明）

  不要直接删掉 —— 读者需要知道「当时是这样，后来变了」
