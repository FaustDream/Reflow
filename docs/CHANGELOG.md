# 更新日志

## 0.1.0（2026-10-21）

首个功能完整版本：10 个平台的订单捕获与导出全链路打通。

### 平台支持

| 平台 | 捕获方式 | 登录方式 |
|---|---|---|
| 闲鱼（买/卖） | 主动抓取 + 被动捕获 | 二维码（原生接口） |
| 淘宝 | 主动抓取（按月）+ 被动捕获 | 二维码（原生接口） |
| 1688 采购 | 主动抓取 + 官方 50 列导出 | 复用淘宝登录 |
| 京东 | 主动抓取（按年）+ 被动捕获 | 二维码（登录页提取） |
| 拼多多 | 被动捕获（观察法） | 二维码（登录页提取） |
| 快手小店 | 被动捕获 + 自动翻页 | 二维码（登录页提取） |
| 得物 | 被动捕获 + 自动翻页 | 小窗登录（无网页二维码） |
| 饿了么 | 被动捕获 + 自动翻页 | 小窗登录（无网页二维码） |
| 美团外卖 | 被动捕获 + 自动翻页 | 小窗登录（无网页二维码） |

### 核心功能

- **统一订单模型**：19 个核心列 + 各平台扩展列，跨平台合并导出
- **导出三形态**：Excel 单表（合并）/ Excel 多表（每平台一张）/ CSV（带 BOM）
- **导出双粒度**：导出本平台 / 导出全部；多账号时可选「仅当前账号」
- **多账号聚合**：同平台多账号独立会话，账号内去重
- **本地缓存**：订单按平台持久化，重启不丢，清空可删
- **自动翻页**：滚动加载型平台一键连续抓取
- **详情二次抓取**（闲鱼）：收货地址/运费/闲鱼币/支付宝交易号
- **商品图内嵌**：Excel 60×60 缩略图，webp 自动转码

### 界面

- 左侧平台列表 + 右侧单表，一屏完成所有操作
- 首次启动引导（原理说明 / SmartScreen 提示 / 选常用平台）
- 工具菜单：诊断快照（无敏感数据）、检查更新

### 安全设计

- 不装证书、不改系统代理、不要管理员权限
- 不构造带签名的平台请求（sign 由页面官方 SDK 计算）
- 订单号精度保护（16+ 位数字不被 JSON.parse 静默舍入）
- 规则热更新通道：SHA-256 校验 + schema 白名单，防投毒
- 无任何授权限制：导出行数恒等于捕获行数

### 已知限制

- 拼多多为被动捕获（接口契约待真机校准）
- 得物/饿了么/美团无纯二维码登录（平台网页端不提供）
- 未做代码签名：首次运行需通过 SmartScreen（见引导说明）
